Facts in Accordance to Timelines:
In 1997 — ECMAScript 1 (ES1)
The first official ECMAScript standard was adopted in June 1997 by Ecma International. 
ECMAScript provided a standardized specification for JavaScript so that different browsers 
could implement the language more consistently.

In 1999 — ECMAScript 3 (ES3)
ECMAScript 3 was released in 1999 and became an important version in JavaScript's early 
history.
Major improvements included:
Regular expressions
Better string handling
error handling
switch statements
Additional language features
Impact:
ES3 provided a much stronger foundation for the JavaScript used on the early web. The next 
major language update would not arrive until 2009.

In 2009 — ECMAScript 5 (ES5)
ECMAScript 5 was approved in December 2009 and represented a major revision of the 
language. It was originally developed under the name ECMAScript 3.1. 
Important features included:
Strict mode: "use strict"
JSON support
New array methods such as forEach(), map() and filter()
Improved object functionality
Better support for working with properties

In  2015 — ECMAScript 2015 (ES6)
ECMAScript 2015, commonly called ES6, was one of the biggest updates in JavaScript's 
history. It was officially adopted on 17 June 2015 and was described by Ecma International as 
the most significant update since 1999. 
Major features included:
let and const
Arrow functions
Classes
Template literals
Default parameters
Destructuring
Promises
Modules
Spread and rest operators

In 2016–Present — Annual ECMAScript Releases
After ES6, ECMAScript moved to a yearly release cycle rather than waiting many years 
between major versions. Releases are now named according to their year, such as ES2016, 
ES2017, ES2018, and so on.
